Setup guide

Get your Deadlock matches into Climb within minutes

Climb gets match data from deadlock-api.com. It only has a game once someone sends it that game’s match key from Valve, which can take hours. deadlock-api’s free, open-source ingest tool sends yours as soon as each game ends.

Install it and forget it

Runs in the background from sign-in. Takes two minutes. Also uses your saved Steam login while the game is closed (see “Your Steam login and data”).

Steps below

Install it (Windows)

  1. Download deadlock-api-ingest-setup.exe from the latest release.

    Open the releases page

  2. Run it. No admin rights needed. If Windows SmartScreen appears, choose More info, then Run anyway.

  3. That’s it. It installs to %LOCALAPPDATA%\deadlock-api-ingest, starts now and every time you sign in, and adds Start menu and desktop shortcuts.

Prefer PowerShell?

This one line does the same install. Run PowerShell as Administrator and it starts from a scheduled task; otherwise it adds a startup entry for your user.

irm https://raw.githubusercontent.com/deadlock-api/deadlock-api-ingest/master/install-windows.ps1 | iex

Only while Deadlock is open

  1. Install it as above. Then turn off the background copy so two don’t run at once: uninstall it, or remove its startup entry in Task Manager → Startup apps.

  2. In Steam, right-click Deadlock → Properties → General → Launch Options, and paste this, with YOUR_USER replaced by your Windows user name:

    "C:\Users\YOUR_USER\AppData\Local\deadlock-api-ingest\deadlock-api-ingest.exe" -- %command%

    Keep any launch options you already use after %command%.

  3. Launch Deadlock from Steam. If Steam says “cannot find the path specified”, the launch option doesn’t work on your PC. Clear the box and use the normal install instead; this has happened on some Windows setups.

Check it’s working

Open the tool’s status window. It shows whether it’s running, how many matches it has sent, and your recent ones. It never uploads anything itself.

& "$env:LOCALAPPDATA\deadlock-api-ingest\deadlock-api-ingest.exe" --gui

Paste it into PowerShell. Play a game, get back to the hideout, and the match should appear in the list within a few minutes.

See your games in Climb

  1. Open Climb and paste your Steam profile link, or search your Steam name.

  2. After a game, wait a few minutes in the hideout, then press Climb’s refresh button (↻).

  3. Missing an older game? With the tool running, open that game in Deadlock’s match history so its scoreboard loads. Then paste its match id into Missing a game? at the top of Climb’s Matches tab.

Your Steam login and data

  • Steam login: while Deadlock is closed, every 30 minutes the installed version signs in to Steam with the saved session of any account that has “Remember me” on, and asks Valve for missing match keys, your friends’ first. It caps itself at 40 match and 20 friend-history requests per account per day. Your Steam session only ever goes to Steam, never to deadlock-api.
  • Turning that off: the tool skips it when started with --no-gc. The launch-option setup above never does it.
  • What it sends: match ids, match keys and your Steam account id to deadlock-api. When it asks Valve about friends’ matches, it also sends their account ids.
  • On your PC: it keeps a local log of what it sent in fetched-salts.jsonl, never changes game files, and is open source (MIT licence).

About reading the game’s memory

While Deadlock is open, the tool reads match keys from the game’s memory. It only reads and never writes to or injects into the game, but reading another program’s memory is the kind of thing anti-cheat systems watch. The risk is small and the tool is widely used, but it’s your call. Starting it with --no-memory turns that part off, at the cost of catching fewer games.

Uninstall

Settings → Apps → Installed apps → deadlock-api-ingest → Uninstall. Or in PowerShell:

& "$env:LOCALAPPDATA\deadlock-api-ingest\uninstall-windows.ps1"

On Linux, install with curl -fsSL https://raw.githubusercontent.com/deadlock-api/deadlock-api-ingest/master/install-linux.sh | bash and remove with ~/.local/share/deadlock-api-ingest/uninstall-linux.sh.
